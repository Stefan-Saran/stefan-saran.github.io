# Moonlit Ascent

A responsive cinematic neon precision runner based on the supplied moonlit reference.

## Controls
- Desktop: A/D or Left/Right to move lanes, Space/W to jump, Escape to pause.
- Mobile: swipe left/right, tap or swipe up to jump, or use the large touch zones.

## Features
- Smooth lane movement with jump buffering and coyote time
- Procedural platform patterns with increasing speed
- Landing/combo/perfect-hit feedback
- Animated moon, mountains, fortress, pagoda, bamboo, lanterns, particles and water-like accents
- Responsive chase camera with shake and forward sway
- Persistent best score using localStorage
- Original Web Audio electronic/trap-style loop; no copyrighted commercial recording bundled
